# Solver Visualizations

This directory contains automated visualizations of the core numerical methods implemented in NUM-CORE. These are used in the main README and documentation to demonstrate the suite's capabilities.

- **`convergence.png`**: Step-by-step bracket narrowing in the Bisection root-finding method.
- **`calculus_plot.png`**: Visualization of the area under the curve for numerical integration ($sin(x)$).
- **`regression_plot.png`**: Least Squares linear fit applied to a sample experimental dataset.
